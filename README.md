# CodeAlpha_StockPortfolioTracker
# CodeAlpha Python Project

### 1. Stock Portfolio Tracker

A Python-based stock portfolio tracker that calculates the total value of selected stocks based on their prices and quantities.

#### Features
- Allows users to enter stock symbols
- Accepts stock quantities
- Uses predefined stock prices
- Calculates individual stock values
- Calculates the total portfolio value
- Displays portfolio information clearly

#### Technologies Used
- Python
- Functions
- Dictionaries
- Conditional statements
- User input and calculations
